# Charles Cao

**Founder building the infrastructure layer for AI agents: inference, orchestration and deployment.** Montreal, Canada.

I founded **MegaNova AI**, the enterprise AI platform. We ship:

- **[LibraOS](https://libraos.com)**: describe an AI app, build it with AI, deploy it to the cloud or your own infrastructure.
- **[AgentD](https://libraos.com/agentd/)**: a supervised software factory for Claude Code and Codex. Free locally.
- **[MegaNova Cloud](https://meganova.ai)**: 100+ LLMs behind one OpenAI-compatible API.
- **[veil-detect](https://huggingface.co/libraos/veil-detect)**: open-source PII detection before text leaves the machine.

Before MegaNova, I founded **SwanChain**, an AI DePIN network with **1,000+ GPU providers**. Earlier, I spent **12+ years** in software engineering at **IBM, SAP, Autodesk and Expedia**.
