# Charles Cao

**Founder building the infrastructure layer for AI agents: inference, orchestration and deployment.** Montreal, Canada.

I founded **MegaNova AI**, the enterprise AI platform. We ship **[LibraOS](https://libraos.com)**, which turns an idea into an AI app: describe what you need, build it with AI, then deploy it to the cloud or run it on your own infrastructure. The **LibraOS Runtime** provides agents, memory, knowledge, tools and policy controls (approvals and audit), measured at **244 runs/s at 256 concurrency**. **LibraOS Cloud** (private beta) takes an idea to a validated AI app with grounded answers, human approval, export and deploy. **[MegaNova Cloud](https://meganova.ai)** serves **100+ LLMs** behind one OpenAI-compatible API, and **Character Studio** is a no-code AI agent builder.

Before MegaNova, I founded **SwanChain**, an AI DePIN network with **1,000+ GPU providers**. Earlier, I spent **12+ years** in software engineering at **IBM, SAP, Autodesk and Expedia**.
